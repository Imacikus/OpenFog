# Archive (frozen legacy)

This directory contains the **previous** OpenFog implementation and its release
artifacts. It is **frozen**: nothing here should be modified, migrated, or
referred to as the active application.

Contents:
- `fog-of-world-web/` – the old web app (Vite + vanilla JS + Leaflet + Capacitor).
- `openfog/` – the old F-Droid Capacitor Android project and its release keystore config.
- `metadata/` – F-Droid yaml metadata and `fastlane/` store metadata for the old releases.
- `README.md` / `CHANGELOG.md` – docs for the old app.

The current, active application lives in the `native/` directory (Kotlin +
Jetpack Compose + osmdroid). The web app is no longer maintained.

This legacy code is preserved only for historical reference. Do not edit it.
